ng Run: City Rush website

This is a static website. The game runs in the browser and saves coins, best score, and unlocked skins in that browser's local storage.

## Publish it free with GitHub Pages

1. Sign in or create an account at https://github.com/
2. Create a new public repository named `gng-run`.
3. Upload `index.html` from this folder to the repository root.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then save.
7. Wait a minute or two. GitHub will show your website URL in the Pages section, usually:
   `https://YOUR-USERNAME.github.io/gng-run/`

You can then open that URL whenever you want, on desktop or mobile. The site remains available while the hosting account and repository remain active.

## Notes

- This is a static website, so no server or API key is needed.
- Saved progress is browser-specific. It does not automatically sync between devices.
